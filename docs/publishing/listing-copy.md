## Directory description

OpenVid is a self-hosted video presentation editor with an editable scene timeline. It supports text, shapes, images, video and audio layers, timing controls, animations, narration and background music. Finished videos render locally with HyperFrames.

The repository includes six complete business example projects with assets and finished videos. Editing and rendering existing media require no AI provider key. Optional generation connects to supported provider accounts for scene planning, images, speech, music or video, with charges billed by those providers.

The application uses Python/FastAPI, JavaScript, FFmpeg and HyperFrames. Its source is AGPL-3.0-only; example media retains separate notices. Current limitations include no Google Drive integration or live collaboration across workspaces. PDF/PPTX imports preserve pages as images, and project JSON exports do not bundle media.
