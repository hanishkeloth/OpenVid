02 / 11
02 / INSTALL

Clone and install OpenVid

Run these commands in your terminal
git clone https://github.com/hanishkeloth/OpenVid.git
cd OpenVid
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
npm ci

This creates a local Python environment and installs the pinned project dependencies.

09 / 11
09 / CHECK

Verify the exported file

Playback is the final quality check
ffprobe -v error -show_entries \
  stream=codec_type,width,height,duration \
  -of json your-video.mp4

ffmpeg -v error -i your-video.mp4 -f null -

These commands inspect streams and decode the file. Also check readability, voice timing and music volume.
