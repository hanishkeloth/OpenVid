## LinkedIn

I’m sharing OpenVid, an open-source video presentation editor you can run on your own computer or server.

Keep scene editing and export in one workspace, while choosing the AI providers you want for planning, images, speech, music, or video.

The first version includes editable scenes, native animations, recording and document imports, voice profiles, local HyperFrames export, and six complete business examples with narration, music, assets, and finished videos. Existing media can be edited and exported without an API key; optional AI generation is billed to connected accounts.

Code is AGPL-3.0. The project is early, and model support varies. Feedback on editing, setup, and provider adapters would be useful.

Source: https://github.com/hanishkeloth/OpenVid
Examples: https://hanishkeloth.github.io/OpenVid/
