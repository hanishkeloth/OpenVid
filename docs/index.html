Good to know

Before you start.

Is OpenVid free?

The application source is available under AGPL-3.0. Editing and rendering existing assets use your own computer or server. Optional AI generation is billed by your chosen providers.

Can I use my own API keys?

Yes. Connections supports the listed provider APIs and compatible endpoints. A key from an unrelated service does not automatically work; models must match the adapter’s API format.

Does OpenVid include voice cloning?

ElevenLabs integration includes voice profiles, a voice library, design, and consent-gated cloning. Provider plan requirements, language support, and verification still apply.

Is this a complete Google Vids replacement?

OpenVid is an independent video presentation editor. It supports scene editing, generation, recording, imports, and export. It does not include Google Drive integration, Workspace accounts, or cross-workspace live collaboration.

Can I contribute or self-host?

Yes. The repository includes source, tests, Docker configuration, provider notes, and examples. Read the contribution guide and preserve the software and asset notices when sharing your version.
